# 相速度与群速度提速：0.6.0.dev6

同一台 Threadripper PRO 3955WX（16 核）与 RTX 5090，CUDA 设备 1，FP64；8/32 层，12 个周期（2–50 s），基阶 Rayleigh。CPU 线程预算分别为 1、16，CUDA 独立在 GPU 寻根及求导。预热后同步整批计时，9 次中位数；模型和网格已准备好，每次重新求根，没有缓存解。完整建模调用另列。旧版为已发布 dev5 二进制；新版为源代码提交 `54cf35f` 的本机 Release 构建。

## 精度与实现

33 个模型、1130 个有效模态/周期点，包含低速夹层、密度强反差、薄层、厚层短周期、乱序与重复周期；CPU 和 CUDA 都通过原始复数 GRTM 全扫描对照。最大相速度差 1.73e-12 km/s。8 个模型的 70 位精度独立矩阵参照：相速度误差不超过 1.51e-12 km/s，群速度不超过 1.21e-10 km/s。新增 mode 1/2 的 Vs 核有限差分检查（含 8 s Love 截止附近），容差 rtol=atol=1e-6，通过。17 项面波测试在 CUDA 上全部通过，Apple CPU 通过 14 项、跳过 3 项 CUDA 测试。

改动：实数试算求得更紧以减少复数 Newton 修正；CUDA 分开扫描、试算和复数括区验收，疑难点仍在 CUDA 上完整回退；大批量基阶按序扫描并提前停止，小批量保持全网格并行；薄层展开利用最小多项式压缩为四次状态递推，保留原有 Taylor 阶数；小型 CPU 群速度任务减少线程启动。FP64、模态索引、搜索网格、1e-8 复数残差门槛和用户根容差未放宽。

需要同时获得相速度和群速度时，使用一次 `result = sw.dispersion(periods, kind="group")`，读取 `result["phase_velocity"]` 和 `result["velocity"]`，只寻根一次。

本轮仅修改面波计算；格林函数 CUDA 反向 AD 和 FFT/物理合成优化另行推进，不能计入本表。
