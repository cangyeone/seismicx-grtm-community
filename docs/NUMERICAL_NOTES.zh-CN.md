# 物理约定与数值适用范围

[English](NUMERICAL_NOTES.md) | 简体中文

点源模型支持水平各向同性固体层，末层为半空间；暂不支持流体、各向异性、倾斜层和零震中距。
高层接口默认 NED/SI，原始 `compute()` 和 CLI 使用 native 单位。
无震源历史时输出为脉冲核，不能直接当作静态位移或应力。

有限 Q 的默认应力约定为实参考 `mu=rho*Vs0**2`、复波速 `a,b` 和
`lambda=mu*((a/b)**2-2)`，与继承的内核一致，不等同于常规实密度粘弹性关系 `mu*=rho*b**2`。
CPU/GPU 一致不能独立验证某种衰减物理模型。`constitutive="elastic"` 使用参考弹性参数，
在有限 Q 下是明确的近似。应力取接收点所在层参数，界面点采用上侧约定，应力以拉伸为正。

同网格的一致性不等于波数积分已收敛。应根据频带、深度、距离和层间对比检查采样、
时间窗及积分精度。浅源高频和极长周期应单独验证；扩展精度也不保证所有问题可靠。
极长周期结构导数目前仍缺少可靠性验证。

点源结构切线仅对冻结的局部积分网格与分支求导，不对层数、震源/接收点所属层变化、
整数截断和 PTAM 极值选择求导。结构反向仍在 CPU 执行，只支持一阶导数。
JAX 构造稠密 Jacobian；NumPy/PyTorch 可用 VJP 避免保存完整结构 Jacobian。

接收函数是独立的弹性平面 P 波模型，忽略 Q；需统一符号、滤波、归一化和时间窗。
反演使用结构参数差分导数。成功终止、满秩和很小的协方差标准差都不能证明地球模型正确；
协方差仅代表固定假设下的名义局部尺度，不包含固定 Vp、地幔或模型失配的不确定性。

详见[接收函数说明](RECEIVER_FUNCTIONS.zh-CN.md)和[FK 对比条件](../benchmarks/fk/README.zh-CN.md)。
