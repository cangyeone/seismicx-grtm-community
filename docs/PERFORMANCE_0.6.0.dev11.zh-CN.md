# 频散能量图：精度与速度，0.6.0.dev11

测试最终安装的二进制包；本表计算整幅受迫响应图，不是已有频散曲线寻根的加速比。

硬件：Threadripper PRO 3955WX 16 核 + RTX 5090；CPU 分别使用 1/4 线程，CUDA 为 GPU 1。FP64，64 个频率 × 256 个相速度；包含返回复响应、原始幅值平方、有效掩码和按频率归一化。每种配置预热一次，3 次同步墙钟时间中位数；不含模型对象构建及结果回传主机。全部网格点有效。

CPU/CUDA 复响应最大相对 L2 差异：**2.246e-13**；归一化图最大绝对差异：**1.155e-12**。独立完整 P/SV 波动方程对照覆盖 1/3/8/32 层，最大相对 L2 误差 **4.634e-14**。另有 SH 半空间/单层解析解、同层拆分、震源与密度缩放、单位转换测试。

Rayleigh/Love 第 0–2 阶共有 12 个存在模态的局部峰检验；在 η=2e-5、速度间距 4e-5 km/s 且根不与网格点重合时，峰位与频散根最大差异 1.480e-05 km/s。该结果仅针对这些局部窗口，不保证所有模型或默认展宽下同样的峰位精度。

两平台各运行 158 项安装包回归测试：macOS 通过 126、平台跳过 32；Linux/CUDA 通过 148、跳过 10，无失败。两份 wheel 均通过无实现源码泄漏及元数据/校验和审计。
