# FP64 特征函数核与受迫伴随：性能与验证 — dev8

[方法与接口](VARIATIONAL_KERNELS.zh-CN.md) · [安装及 ABI 限制](PREVIEW_0.6.0.dev8.zh-CN.md)

比较实际安装的编译包。CPU 为 4 个原生线程、Torch 1 线程；CUDA 为 RTX 5090 GPU 1，计时显式同步。2 次预热、3 次测量取中位数，FP64。相速度/群速度均包含 8 个周期、全部层厚/Vp/Vs/密度核；原生单位，Rayleigh 基阶，根容差 1e-11 km/s。32 层时共 128 个参数，半空间厚度核为零。模型/网格/批量规模和全部样本见原始数据及测量协议。

## 面波：同一 dev8 编译包内比较

同机 CPU/CUDA 对比（两者均为新能量法），32 层、B=32：

- phase: **2.92×**.

- group: **2.60×**.

CPU 群速度的大比值与旧路径在临界模态坐标附近触发逐参数解析保护有关。按实测根和旧代码阈值确认：8/32 层各 1 个周期、96 层 3 个周期触发该保护（每组共 8 个周期）。新能量法在这些样例没有触发保护，不能将该比值推广到所有模型。CUDA 的 B=32 相速度能量路径仍略慢，根搜索和启动开销占比高；群速度则有改善。不要用 Apple CPU 与另一台机器的 GPU 混算同机加速比。

## 格林函数：全部参数与单参数的差异

32 层、B=4、16 个时间样点、32 个固定波数步。这里比较既有解析伴随与逐参数解析切线，并非宣称 dev8 新增了格林函数体积积分核或新的反向引擎。CUDA 切线路径含既有主机合成，CUDA 伴随路径使用已有 GPU FFT/物理合成，因此是整条路径对比。仅求一个参数时伴随常更慢。

## 精度与发布验证

360 条计时记录。面波能量核相对逐参数解析参考的最大绝对差为 **3.565e-10**（原生单位各分量）；这些性能样例能量保护回退 **0** 次。Green 伴随相对解析切线的最大相对范数差为 **5.650e-14**。

实际发布包完整测试：Apple 133 项，110 通过、23 跳过；CUDA 主机 133 项，124 通过、9 跳过。涵盖 Love/Rayleigh 0–2 阶、低速层、重寻根有限差分、解析周期导数、密度缩放、缺根与临界点保护、RF 独立张量图与衰减、Green 物理场/源参数/掩码/低频保护等。跳过由设备或可选依赖决定。数值一致性不证明任意模型不会漏根，不证明反演后验更准确。

发布范围为 Mac CPython 3.12 和 Linux CPython 3.13 两个包；Metal 复用未改动的 dev7 预编译组件。没有声称未启动的 GitHub CI 构建通过。详见安装指南和 SHA256/测试记录。
