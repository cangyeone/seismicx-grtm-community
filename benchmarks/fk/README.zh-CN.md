# 与 FK 的速度对比

[English / 完整说明](README.md) · [首页](../../README.zh-CN.md) · [全部中位耗时](TIMINGS.md)

对比覆盖 Apple CPU、Apple Metal/MPS、远程 CPU 和单张 RTX 5090，并包含
FK 单线程和本研究添加的 FK OpenMP 多线程版本。
测量来自锁定的 **GRTM 0.5.0 科学计算版本**（`e7283a90092652f2037e779540d795edd3d404c5`），
不是对 **0.5.1 PyPI wheel** 的新一轮测速。FK 来自
[Lupei Zhu 的 FK 仓库](https://github.com/rwalkerlewis/fk)，锁定提交
`cde4086f8cb919983c4bcc88fb63b84c8ba24cb1`。

## 比较范围

- Apple M4 Max：FK 1/16 线程、GRTM CPU 1/16 线程、Metal（16 个主机线程）。
- 远程 Threadripper PRO 3955WX，16 核 32 逻辑处理器，WSL：FK 1/32 线程、
  GRTM CPU 1/32 线程、RTX 5090（32 个主机线程）。
- 单线程未绑定固定 CPU 核；远程测量处于**共享负载**，未停止其他进程。
  案例前后的负载记录不能消除每次测量的资源竞争。
- 上游 FK 是串行程序。图中的 FK OpenMP 是本研究单独实现的频率并行适配，
  使模型 COMMON 块线程私有，并保留原物理运算；不能理解成原版自带多线程。
- FK 通过 FP64、固定整数积分网格和内存输出适配调用，不包含 SAC 文件写入，
  不等于直接运行原版 `fk.pl` 的耗时。FK 本身也已将传播核放在接收点循环之外。

每个案例各实现使用相同单力源、相同 5 个非零位移基函数通道及相同积分网格。
计时包括输入准备、积分、GPU 传输与同步、主机 FFT/阻尼及返回数组；排除导入、
求解器初始化、网格选择、验证和归档。GRTM 原有临时模型文件开销计入。
C/CUDA/FK 使用 FP64，Metal 使用 FP64 主机传播与补偿浮点对 GPU 收缩。

15 个案例 × 10 个配置，每配置 2 次预热、5 次轮换顺序测量。
全部 **750 次计时、300 次预热**均公开，未删除慢样本。

## 如何读图

- a/b：接收点数 1、16、64、256；分别相对同一主机的单线程/多线程 FK。
- c：完整调用耗时；d：GRTM 相对本机 C 单线程、FK 多线程相对 FK 单线程。
- e：层数 4、8、16、32、64（包含半空间），64 个接收点，相对多线程 FK。
- f/g：震源深度 1、8、25、45 km 和震中距 1、10、100、1000 km，相对多线程 FK。
- h：独立的 GRTM 距离复用消融，固定网格、线程数和采样，对比复用开关，
  包含正演、目标函数+VJP、一次优化更新；不是 FK 对比。

接收点/层数实验使用 256 点、0.5 s 采样，共用固定网格；距离 10–30 km，
单接收点案例实际为 **10 km**（表中的名义距离标签为 20 km）。
几何实验使用 256 点、2 s 采样，接收距离为名义值的 0.9–1.1 倍；
每个几何案例内部共用网格，不同案例的积分工作量可以改变。
全案例 Qp=Qs=10000。详细模型和网格见 [protocol.json](data/protocol.json)。

加速比是“基线中位耗时 / 当前实现中位耗时”：**大于 1 更快，小于 1 更慢**。
误差棒由观测最小/最大耗时的保守比值构成，不是置信区间。
不同主机硬件间的速度差不能解释为纯算法加速。

## 代表性结果

| 案例 / 设备 | 耗时 | 相对 FK 单线程 | 相对 FK 多线程 | 相对 GRTM C 单线程 |
|---|---:|---:|---:|---:|
| 4 层、256 接收点 / Metal | 0.0808 s | 42.27× | 3.58× | 35.87× |
| 4 层、256 接收点 / RTX 5090 | 0.7387 s | 43.54× | 2.85× | 23.88× |
| 64 层、64 接收点 / Metal | 0.4339 s | 见完整数据 | 0.45× | 见完整数据 |
| 64 层、64 接收点 / RTX 5090 | 1.3102 s | 见完整数据 | 0.94× | 见完整数据 |

后两种情况下多线程 FK 更快，因此不能用最大加速比代表所有模型。
FK 自身多线程加速为 Apple 10.56–12.06×、远程 7.26–15.27×。
完整结果见[计时表](TIMINGS.md)。

所有通道的最大相对 L2 差异：波形 5.531×10⁻⁵，频谱 1.814×10⁻⁵；
120 项串行/OpenMP FK 对比逐位相同，计时输出哈希稳定，无一致性阈值失败项。
这只说明**同网格结果一致性**，不能替代积分收敛或任意有限 Q 的物理验证。
